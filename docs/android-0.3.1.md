# Android 0.3.1 Alpha

包名 `com.easysub.app`，versionCode 6。本次只更新 Android 客户端，服务端与网页仍为 v2.1.0。覆盖安装同签名的 0.3.0 即可保留本地资料，不要卸载或清除数据。

安装文件：GitHub Release `android-v0.3.1-alpha` 中的 `EasySub-0.3.1-alpha-debug.apk`（SHA-256 见同页 `SHA256SUMS-0.3.1`）。仍使用本机调试签名。权限与 0.3.0 相同。

0.3.0 的功能、权限与签名说明见 [Android 0.3.0](android-0.3.0.md)。

## 修复：手机端汇率

以前手机只能从服务器同步汇率，「刷新汇率」按钮被禁用，没有同步到汇率的币种一直显示「未缓存」。

- **直接联网获取**：手机自己请求 `https://open.er-api.com/v6/latest/<基准币种>`，与网页后端使用同一个免费接口，不经过服务器，未连接服务器时也能用。
- **刷新时机**：设置 →「汇率表与刷新」可以随时手动刷新；打开 App 时，如果汇率超过 12 小时没更新会自动刷新，失败时不提示。页面显示上次更新时间。
- **离线**：联网失败时保留上次缓存的汇率，并提示检查网络。
- **自定义币种**：继续使用手动汇率，联网刷新不会覆盖。内置币种如果手动改过汇率，刷新后会换成最新汇率。
- **与同步的关系**：联网汇率单独保存在手机上，不上传服务器；同步时不会被清掉。手机缺少某个币种的联网汇率时，仍会使用服务器同步来的汇率。
