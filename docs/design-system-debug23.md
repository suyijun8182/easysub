# EasySub App Design System · debug23

状态：设计与前端交付稿。基于 OPPO A56 5G 的现有真机截图和源码提炼；第二版重排界面尚未完成视觉验收。设计规范不等同于全量组件已迁移。

配套 tokens：`frontend/src/android-preview/design-tokens.css`。作用域仅限 Android 客户端入口；网页继续使用现有主题。

## 1. 产品判断

EasySub 是个人订阅、服务器续费和 SIM 保号的管理工具。它需要让人迅速认出订阅、判断到期风险、准确记录续费，并放心保留本地资料。

目标用户是同时管理多个数字服务、VPS 或保号号码的人。常用场景是短时间查看近期到期、在完成实际付款或保号操作后记录续费，以及在手机和网页之间核对资料。单个用户可能有多个同名商家的不同号码或套餐，因此商家名称不能独自承担身份识别。

产品气质确定为“有秩序的个人账本”：文字和日期优先，品牌图标帮助识别，状态颜色帮助判断，动效解释操作结果。主要任务不能依赖炫技手势。

| 设计原则 | 适用场景 | 不要怎么用 |
| --- | --- | --- |
| 身份先于装饰 | 订阅卡、续费核对、冲突记录至少出现名称，以及备注/号码/套餐中的一个辨识字段 | 不只显示商家名和一个图标，尤其是同名订阅 |
| 一屏一个主动作 | 总览以查看风险为主，选择后以核对续费为主 | 不让添加、筛选、同步、续费都成为同等大小的主按钮 |
| 信息随任务出现 | 时间滚轮在筛选面板，续费方式在核对面板 | 不将所有控件常驻堆在页面上迫使用户滚动 |
| 结果必须可信 | 成功对勾只在保存成功后出现，部分失败保留具体待处理项 | 不在请求开始或点击瞬间播放成功动效 |
| 状态有文字 | 过期、将到期、暂停同步、已选择均有文字或控件语义 | 不只靠红绿区分状态 |
| 用户字号是约束 | 小屏、长备注、中英俄及系统放大字体 | 不关闭字体缩放，不以截断关键信息换取整齐 |

## 3. 色彩系统

| 语义 | 浅色 | 深色 | 适用场景 | 不要怎么用 |
| --- | --- | --- | --- | --- |
| 页面底 | #f6f7f5 | #0f1113 | 页面与分区之间留白 | 不在一个页面随意增加第二种底色语言 |
| 主表面 | #ffffff | #171a1e | 卡片、底部面板、输入框 | 不用半透明玻璃承载账目和号码 |
| 次级表面 | #eef0ee | #1f2328 | 非主动作、筛选标签 | 不叠加多层灰底造成脏感 |
| 主文字 | #16191d | #eceef0 | 名称、金额、标题 | 不将所有文字都设为主文字而失去层次 |
| 次级文字 | #59606a | #9aa2ad | 日期、币种、说明 | 不使用 text-faint 显示必要信息 |
| 主操作 | #1b1f24 / 白字 | #eceef0 / #111315 字 | 核对、保存、确定 | 不把删除也做成普通主按钮 |
| 正常/选择 | #0f7352 / #e3f3ec | #3dd68c / #12291f | 已选择、正常状态、进度 | 不把未保存的选择当成保存成功 |
| 将到期 | #9e5b00 / #fdf1dc | #f5b83d / #2e2512 | 将到期日期和数量 | 不用黄色大面积铺满普通订阅 |
| 错误/过期 | #c3352c / #fbe6e3 | #ff6b5e / #32191a | 逾期、请求失败、危险文本 | 不用红色强调普通操作 |

测算：次级字在浅色主表面为 6.35:1，Android 绿色在浅绿表面为 5.09:1，白字在 Android 绿色上为 5.84:1；深色次级文字在主表面为 6.77:1。普通文字至少 4.5:1，图标/控件关键边界至少 3:1。弱分割线不承担控件边界职责。

Ocean、Forest、Purple 是已有可选主题，只改变操作色与底色，不改变风险颜色的含义。默认交付以浅色/深色为主，不能将所有主题重染成绿色。

## 4. 字体系统

| 角色 | 尺寸 / 字重 / 行高 | 适用场景 | 不要怎么用 |
| --- | --- | --- | --- |
| 品牌 | 20 / 700 / 1.3 | 顶栏 EasySub | 不作为页面大标题重复出现 |
| 页面标题 | 24 / 650 / 1.3 | 总览、订阅、续费计划 | 不使用超长问候语占据整屏视觉中心 |
| 分区标题 | 16 / 600 / 1.4 | 到期列表、选择区域 | 不与页面标题同大 |
| 卡片名称 | 16 / 650 / 1.4 | 商家或服务名 | 不用单行省略隐藏同名识别信息 |
| 金额 | 24 / 650 / 1.2 | 精选到期卡金额 | 不给币种同等字号，不混用比例数字 |
| 正文 | 16 / 400 / 1.55 | 核对说明、详情内容 | 不将长正文设成 12 |
| 标签/按钮 | 14 / 550 / 1.4 | 操作、单选项、筛选 | 不通过多次缩字来塞入一排 |
| 辅助信息 | 12 / 400 / 1.5 | 日期、币种、简短备注 | 不用于需要连续阅读的大段说明 |

金额与计数使用 `font-variant-numeric: tabular-nums`；IP/技术标识才用等宽字体。中文与英文使用同一个角色尺寸，俄文按实际文本自然增高。金额默认保留两位，小额高精度币种需按币种精度另设格式，不能直接丢失小数。

## 5. 间距与栅格

| 规则 | 适用场景 | 不要怎么用 |
| --- | --- | --- |
| 4、8、12、16、20、24、32、40 | 控件内部 8/12，卡内 16，区块间 24，页面边距 16 | 不出现无角色解释的 17、23、29 间距 |
| 手机单列，宽度最多 520 | 所有核心任务页面 | 不为塞卡片强制两列订阅列表 |
| 标签和数字分栏，说明可换行 | 卡片身份、金额、日期 | 不把长备注挤进金额列 |
| 主触控区域至少 48×48 | 图标按钮、单选行、底栏项 | 不让 18 图标本身承担触控区域 |
| 相邻独立触控目标至少间隔 8 | 删除与编辑、前后按钮 | 不靠两按钮颜色区分误触风险 |
| 内容底部留出实际导航高度 + 24 + 安全区 | 页面尾部、固定核对条 | 不写死仅为某款手机有效的 bottom |
| 320、360、390、430 CSS 宽度检查 | 窄屏、正常屏、长文本 | 不用物理 720px 作为移动端断点 |

系统放大字号时允许卡片变高、标签分行和按钮整块换行；保留任务顺序，不缩放整张页面。

## 7. 图标与插画

| 规范 | 适用场景 | 不要怎么用 |
| --- | --- | --- |
| 同一套现有 SVG 图标，统一 1.7 描边 | 导航、续费、关闭、展开 | 不混用 emoji 作为系统操作图标 |
| 16/20/24 三档系统图标 | 行尾/按钮/导航 | 不在同一层级随意使用 18、23、27 |
| 品牌图标 32，精选卡 40 | 商家识别 | 不拉伸、不擅自重绘商标、不对商标染色 |
| 缺失图标用名称首字 | 网络失败、本地缺图 | 不为未知商家猜测一个看似真实的标志 |
| 装饰图标 aria-hidden，操作图标有名称 | 辅助技术 | 不让“图标 + 同义文字”重复播报 |
| 空态优先短文案与一个可用动作 | 无到期项目、搜索无结果 | 不用大插画挤占本来可用的操作空间 |

本产品核心页面不需要人物插画或背景纹理；只有引导页确需解释概念时才新增插画，并与账目内容分离。

## 8. 组件与交互状态

| 组件/状态 | 适用场景 | 不要怎么用 |
| --- | --- | --- |
| 主按钮 | 当前页面唯一提交动作 | 不同屏放多个同级黑色主按钮 |
| 次按钮 | 筛选、展开、返回、辅助操作 | 不依赖 hover 才能识别按钮 |
| 选中订阅 | 绿色边界、浅绿底、勾选语义 | 不只改变卡片颜色 |
| loading | 当场显示保存中并防重复提交 | 不先播放成功或默默禁止页面离开 |
| error | 近操作区域给出文字，保留失败项 | 不用绿色 toast 显示错误 |
| success | 完成结果文字与静态对勾始终可读 | 不让粒子成为唯一反馈 |
| bottom sheet | 选择时间范围、核对一组续费 | 不把普通阅读页面都改成弹层 |
| disabled | 原生 disabled、降低强调、明确原因/状态 | 不只设 opacity 却继续响应事件 |

同步状态分为本地、已连接、同步中、失败待重试，不能以“账号登录成功”代替“数据已经同步完成”。

## 9. debug23 七项动效契约

| 要求 | 适用场景与实现标准 | 不要怎么用 |
| --- | --- | --- |
| 按钮与跳转 | 每个入口有真实目标，返回可预测；目标不可达时提供反馈 | 不以静态样式冒充可点击控件 |
| 完成收缩、对勾、粒子 | 保存全部成功后，200ms 裁切成圆，260ms 绘制对勾，450ms 内粒子消失；文字结果持续保留 | 不动画 width/height，不在部分失败时庆祝 |
| 勾选联动 | 选择后进度、计数、背景同时反映同一个选择集合，180–220ms | 不在刷新时清空选择，不让进度超过 100% |
| 卡片堆叠展开 | 收起只展示卡背，展开按 28ms 错峰，单卡 240ms；重复点击应结束/重定向当前动效 | 不让隐藏卡片仍可点击或聚焦，不泄露底层文字 |
| 吸附与时间线 | 一组卡片纵向吸附，停稳后更新当前项和描边；提供前后按钮 | 不与整个页面抢同一拖动，不在未停稳时抖动切换 |
| 惯性滚轮 | 保留速度、阻尼减速、边界回弹，最终只落合法刻度；加减/键盘有等价功能 | 不让惯性无限循环、不锁住页面之外的触摸 |
| 圆形扩散 | 只用于底部页签，触点为圆心、最远角为半径，320ms；单次导航单一转场所有者 | 不叠加 Vue out-in，不把同页重复点击也做整屏动画 |

减少动态效果时取消位移、缩放、粒子与扩散，保留结果文字、选中状态和静态进度。键盘频繁输入直接更新状态。离开页面必须清理计时器与动画帧。这里定义的是交付标准，现有代码的逐帧质量仍需按下表验收。

## 10. 前端使用与验收

CSS 策略：现有主题 + Android 作用域 CSS variables + Vue scoped 组件样式，不引入第二套样式库。

当前接入范围：Android 入口已导入 tokens；页面主标题、总览主标题、分区标题、导航图标、页面边距、触控底线及续费计划的主要圆角和 CSS 动效时长已使用 tokens。共享网页组件、部分历史按钮字号与圆角、JavaScript 惯性物理参数仍待按组件迁移；不要将这一轮接入理解为全项目已完成统一。

```css
.subscription-surface {
  padding: var(--es-space-4);
  border: var(--es-border-width) solid var(--es-color-border);
  border-radius: var(--es-radius-card);
  background: var(--es-color-surface);
  color: var(--es-color-text);
}
.subscription-name {
  font: var(--es-weight-strong) var(--es-text-card) / var(--es-leading-title) var(--es-font-sans);
}
```

| 验收项 | 通过标准 |
| --- | --- |
| 小屏/放大字体 | 320–430 宽；正常及 1.35 字号；名称、号码、金额完整可辨；尾部动作不被底栏遮挡 |
| 多语言/主题 | 中文、英文、俄文；浅色和深色优先，五套现有主题保持风险语义 |
| 七项交互 | 默认、操作中、成功、失败、快速重复操作、减少动态效果均检查 |
| 真实数据安全 | 视觉验收使用隔离数据验证成功动效；真实账号只读检查不提交续费 |
| 证据 | 页面截图、动效前中后画面或录像；单纯构建通过不能算视觉验收 |

当前证据：旧版浅色真机上的字号层级、按钮折行、卡背泄露和转场空白已有观察；后两项已有源码修正。第二版仍缺真机完整截图及逐帧动效检查。设计师应先按本规范审核页面密度与层级，前端再据实际画面调节，而非再次新增装饰性组件。

## 11. 设计红线

| 禁止规则 | 适用场景 | 替代方式 |
| --- | --- | --- |
| 为展示动效增加常驻大区块 | 滚轮、进度、确认说明 | 按任务渐进展示 |
| 关闭系统字号、锁定缩放 | 任意移动页面 | 弹性布局和正确内容优先级 |
| 关键识别文本省略 | 号码、IP、订阅备注、金额 | 自然换行或进入详情 |
| 全站换成同一层级大卡片 | 总览、列表、设置 | 按精选、普通列表、浮层分层 |
| 动画布局尺寸或 transition: all | 所有交互 | transform、opacity、clip-path、明确颜色属性 |
| 无视 reduced-motion | 新动效 | 静态状态同样清楚 |
| 用成功动画掩盖失败 | 提交、同步、备份 | 准确结果和可重试失败项 |
| 暗色主题直接沿用浅色状态字 | 所有可选主题 | 语义主题变量和实际对比度检查 |
| 以“构建成功”作为“设计完成” | 发布和交付 | 明确列出已经看过的画面与剩余缺口 |
