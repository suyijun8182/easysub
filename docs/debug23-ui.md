最新 debug23 已增加产品定位、从截图提炼规则、完整设计系统及 design tokens 的要求。正式设计交付见 [design-system-debug23.md](design-system-debug23.md)，对应 CSS 为 `frontend/src/android-preview/design-tokens.css`。本文件仅保留实施经过与未完成验收项。

## 第二版重新设计

用户明确否定了第一版效果。第一版把动效拆成多个独立大区块、常驻滚轮和长核对说明，小屏上操作路径过长。

- 顶栏改为紧凑品牌、Alpha 信息入口和账号设置，移除两个常驻大按钮。
- 总览保留全部原功能，通过一条续费入口进入计划页面。
- 计划页先显示待安排数量与选择进度，再显示真实商家图标、日期、备注和金额的到期卡。
- 时间范围移至原生 dialog 底部面板，惯性滚轮与加减操作均保留。
- 选择订阅后才出现底部核对操作条，核对面板列出清晰身份与两种续费模式。
- 成功反馈仍只在实际保存成功后出现，错误保留失败项，避免为了演示修改真实日期。
- 颜色继续使用原有语义主题，主要内容字号不低于 12px，不更改手机系统字号。
- CSS 使用已有 Vue scoped 样式与全局移动端主题；不增加动效依赖。

新版 APK 已构建并覆盖安装，预览回归 21 项通过。同步未改变订阅身份/日期时不再重置时间卡位置。底部面板打开时返回键先关闭面板，保存中阻止离开。手机目前锁屏，第二版真机视觉验收尚未完成，下面第一版验证不能视为新版已验收。

需求来源：`需要实现的功能.txt` 的 debug23 七项。

## 设计约定

1. 主题：沿用安静工具风格，以真实续费任务承载动效。
2. 配色：复用 surface、primary、ok、ok-soft 主题变量。
3. 字体：复用 Onest 与中文系统字体，保留用户字号，数字采用等宽数字特性。
4. 组件：新增续费工作台、惯性滚轮，不增加动效依赖。
5. 布局：状态、时间范围、到期时间线、勾选订阅、核对续费。
6. 层次：边框和背景区分选择状态，堆叠用于订阅概览。
7. 约束：勾选不续费；实际提交明确说明会更新日期、不扣款；失败项保留供重试。
8. 响应式：内容自然换行，保留底部安全区，滚轮支持键盘、指针与鼠标滚轮。
9. 交互：使用 transform、opacity、clip-path 和颜色；减少动态效果时保留静态反馈。
