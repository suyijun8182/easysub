# Android 完整功能预览：当前状态

运行：`cd frontend`，`npm run preview:android`。访问 `http://localhost:5174/android-features.html`。旧 `android-prototype.html` 会跳转到同一主机 5174 端口的新版入口。

新版入口复用网页版真实 Vue 页面，而不是另写删减表单。生产网站仍使用原来的入口与 API；演示适配器只在此预览入口加载。

UI 修复进度已更新到 [android-ui-fixes.md](android-ui-fixes.md)：长表单导航、金额显示、配色、触控、设置分组、未保存保护、详情入口与动效均有对应修正。实际手机视觉/交互验收仍未完成。

服务库现已缓存 323 个 favicon，剩余 33 个为首字回退；上传图片可预览并进入加密预览备份。URL 导入受到浏览器跨域限制，失败会显示原因。手机正式版需实现完整离线资源。无缓存汇率时统计页面提示先配置手动汇率，不将缺失金额当作零。已有币种也可通过币种表单设置手动汇率。

普通局域网 HTTP 来源没有 Web Crypto 加解密能力；备份页会显式提示，电脑 localhost 可以体验加密。不会降级为明文备份。安全副本存放在预览会话内存，切换页面保留，刷新清空。

## 仍未完成，不能宣称 App 功能齐全

- Android 原生工程、持久化数据库、安全密钥存储、应用锁、系统通知与重启恢复。
- 后台外部渠道发送/诊断、实时汇率、目录授权和自动备份计划。
- 网页新加密备份格式互通，以及审核发现的网页旧备份漏字段修复。
- 原生返回/跨重启草稿恢复、应用锁删除认证、全流程无障碍与真机视觉验收。预览独立详情页及日历入口已增加。
- 签名 APK、安装/升级验证、GitHub 正式发布。

本轮交付是补齐功能入口与主要操作的**设计预览**，不是已完成的离线 App。预览状态仅在内存中保存；刷新即重置。备份文件格式明确标记 `encrypted-preview-v1`，不可冒充已经兼容网页的正式格式。

## 验证

`npm run test:android-preview` 覆盖计费起算、字段/关联/汇率/记录恢复、无效日期、主键保护、加密解密与错误密码、CSV 引号、所有个人查询接口、14 渠道数量与发送拒绝。

`npm run build:android-preview` 单独构建预览；`npm run build` 校验原网站构建与国际化。浏览器 UI 控制被当前工具权限拒绝，尚未进行浏览器和手机视觉验收。
