## 配色再次检查

检查 light/dark/ocean/forest/purple 五组有效令牌的正文、辅助文字、主操作、危险操作和三种状态标签，所有被测文字/背景对均达到 4.5:1。浅色绿色状态标签从 4.29:1 调整为 5.09:1。跟随系统使用相同 light/dark 令牌，不另设一套颜色。

这是静态色值计算，不覆盖渐变、透明叠加、禁用态、所有图表配色或手机屏幕实际显示，不等于完整无障碍认证。
