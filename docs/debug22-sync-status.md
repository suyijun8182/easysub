# debug22 实现与验证记录

本文件记录浏览器同步阶段。后续已建立 Android 工程并生成 Alpha APK，新增原生存储、返回键及文件导出，当前进展与剩余范围见 [android-alpha.md](android-alpha.md)。

本阶段交付服务器协议和持久化浏览器测试客户端。不是 Android APK，也不代表真机验收完成。

## 运行与使用

在 `frontend` 运行 `npm run preview:android`，打开 `http://localhost:5174/android-app.html#/settings/sync`。原 `android-features.html` 继续提供隔离演示，不上传示例数据。

本地应用首次启动为空订阅列表。先单机录入，或填写网页服务器地址、已有用户名、密码及可选两步验证码，点击“测试连接”，核对服务器、账号和两端数量后“确认保存并开始同步”。账号不存在时提供该服务器注册入口；密码错误、验证码、邮箱验证、审批及禁用状态不误导为注册。

浏览器运行环境须支持 WebCrypto、IndexedDB、Web Locks、AbortSignal.any。远程服务器要求 HTTPS，本机调试允许 localhost/127.0.0.1。手机访问电脑局域网 HTTP 不满足安全存储环境，应使用 HTTPS 或 ADB reverse 后的手机 localhost。没有绕过 TLS。

服务器须部署本次后端代码；启动时现有 `Base.metadata.create_all` 创建四个新增同步表，不修改旧业务列。MySQL 连接改用 READ COMMITTED，每个账号的业务写和同步变更日志在同一事务中提交。生产环境尚未部署或执行 MySQL 并发验证。

## 已实现

- 全字段订阅、分类、付款方式、捆绑包、自定义币种及手动汇率、业务偏好、14 渠道通知配置。设备主题/语言留在本地，账号认证及两步密钥不作为业务同步数据。
- UUID、递增版本、账号隔离游标、世代标识、删除墓碑、操作回执、批量提交、分页和明确冲突。数据库恢复替换切换世代，旧设备自动暂停，防止回写复活。
- 前台每 15 秒、恢复联网及回到前台自动同步；请求丢失重放同一操作 ID。用户使用本地页面时可中止等待中的网络同步，本地保存不等待网络超时。
- AES-GCM 加密 IndexedDB 单文档原子保存业务资料、游标、待传队列、冲突与令牌。浏览器生成不可导出 CryptoKey，密码和验证码不保存。此方案不是 Android Keystore，无法抵御同源恶意脚本或已控制的设备。
- 单文档生命周期独占 Web Lock，第二标签拒绝启动，避免旧快照覆盖。世代、服务器和账号变化不会自动混合，需备份并使用独立资料库；退出登录清除本地令牌但保留数据和绑定身份。刷新令牌沿用现有服务器机制，未实现服务端逐令牌撤销。
- 本地图像先上传，服务器图标按所属同步记录认证下载并缓存。缓存失败保留源地址，下次重取；远程 URL 图片仍依赖其原始服务。生产构建的 Service Worker 缓存页面和静态脚本，不缓存 API/密钥响应。
- 自定义币种代码仍受现有服务器全局唯一约束。首次碰撞拒绝合并；增量碰撞保留本地映射与双方版本，禁止重复投影吞掉修改。保留本地币种须改用其他代码，不能覆盖系统币种或他人的同代码币种。
- 备份补齐试用、取消截止、卡信息、创建时间、预算、提醒配置、分类排序及自定义汇率；恢复仅写本账号自定义汇率，不覆盖公共汇率。旧文件没有的字段继续兼容。

## 验证

- `backend`: `\.venv\Scripts\python.exe -m unittest discover -s tests -p test_sync.py`：11 项通过。覆盖事务、分页、完整字段、跨账号拒绝、加密日志/回执、删除、幂等、无效操作隔离、备份恢复世代、图标认证和路径边界。
- 前端同步及既有预览测试：24 项通过，包含真实 HTTP 联调；其中 1 项需先启动下方隔离 fixture。其余测试不需要服务器。
- `npm run build`、`npm run build:android-preview` 均通过。默认同步测试会跳过需服务器的 HTTP 项，不能据此宣称联调已执行。

重跑真实联调：在 backend 使用虚拟环境运行 `python -m uvicorn tests.sync_fixture:app --host 127.0.0.1 --port 18765`，另一个 frontend 终端设置 `$env:EASYSUB_SYNC_FIXTURE='1'` 后运行 `node --test src/sync/*.test.js src/android-preview/*.test.js`。fixture 使用独立 SQLite 内存库，关闭进程即丢弃；不会打开现有应用数据库。测试账号只用于该 fixture。

## 未完成的验收

Android 工程/APK、Keystore、系统通知、后台任务、进程终止与重启恢复、OPPO 省电策略、物理手机双端操作仍待实现和验证。此轮没有浏览器截图、真实 IndexedDB/Web Locks/Service Worker 离线操作证据，也没有生产 MySQL 并发测试。浏览器清除站点数据会移除本地资料及密钥，需另存备份。

单账号首次合并保留不同身份的同名记录，不自动猜测去重。服务器资料库世代改变后保留本地数据并暂停，目前通过导出备份和建立独立资料库重新连接，尚无自动恢复向导。
