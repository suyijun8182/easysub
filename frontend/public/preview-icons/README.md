# Service icons for the EasySub design preview

These favicon files were cached from the service domains already listed in
`src/android-preview/seed.json`, using Google's public favicon endpoint, or
copied from the existing local EasySub icon cache. They identify the respective
services; trademarks remain with their owners. They are not EasySub artwork.

Run `python scripts/cache-preview-icons.py` to refresh missing files.
`src/android-preview/cached-icons.json` lists successful downloads; unavailable
icons use a local initial fallback. The preview does not fetch icons on render.
