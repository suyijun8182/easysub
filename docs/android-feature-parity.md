# Android 功能迁移核对表

原则：小屏调整展示层级，不删个人功能。样稿中的字段或按钮不等于功能已实现。以下按现有 Vue 页面和后端路由建立迁移基线，开发时逐项验证；不以此初始清单宣称已完成全量审计。

| 模块 | 必须迁移的能力 | 手机呈现 |
| --- | --- | --- |
| 服务库 | 完整预设服务、13 类浏览、搜索、名称联想，选择后带入名称/分类/网站/图标 | 新增页服务选择区，分类选择器与滚动结果 |
| 图标 | 内置库、手机图片上传、URL 下载、Emoji，自定义图标与备份互通 | 新增/编辑页独立图标区，预览与更换 |
| 基本字段 | 名称、套餐、分类、金额、币种、备注 | 分组表单 |
| 周期日期 | 周期订阅/买断、自定义数量与单位、开始日、下次续费日 | 基本字段及展开设置 |
| 提醒状态 | 自定义提前天数、启停、自动续费、日历可见性 | 提醒与高级设置 |
| 扩展资料 | IPv4/IPv6、家庭成员、捆绑包加入/创建、网站、详细笔记 | 可展开分组，详情页完整查看 |
| 风险日期 | 试用结束、取消截止、付款卡末四位与到期 | 更多信息与提醒计划 |
| 列表 | 搜索、分类分组、筛选、排序、分类与订阅手动排序 | 搜索与筛选，专门排序模式 |
| 操作 | 详情、编辑、续费起算方式、启停、删除、批量续费/分类/启停/删除 | 详情操作与长按批量选择 |
| CSV | 订阅导入与导出、报表导出 | 列表/报表菜单，系统文件选择 |
| 总览 | 到期事项、月年支出、预算、分类支出、近期记录 | 按处理优先级纵向展示 |
| 日历 | 月历、当日议程、订阅详情、ICS | 月历与议程，ICS 文件导出 |
| 报表 | 总览、洞察、分类明细、最近付款、时间筛选 | 图表与可读明细 |
| 基础配置 | 分类、支付方式、捆绑包、币种、预算、主题、语言 | 设置分组与独立管理页 |
| 通知 | 原有全部渠道的配置/测试/记录、免打扰、每周摘要 | 本地通知为默认，外部发送需联网 |
| 汇率 | 更新、缓存、换算与更新时间 | 无网使用缓存并标记 |
| 备份 | 网页个人/整站导入、用户选择、追加/替换、完整加密导出、自动备份、密钥/图标/关联恢复 | 独立备份恢复流程 |
| 隐私记录 | 应用锁、通知记录、操作日志 | 设置入口 |
| 更新发布 | 版本信息、GitHub 发布与 APK 升级保留数据 | 关于与更新 |

已确认的环境差异：无服务器账号/管理员/注册/2FA/API Token 管理；应用锁保护本地使用；Home Assistant 服务接口留在网页服务；ICS 采用文件导出；后台任务遵守 Android 限制。这些是已确认的替代边界，不是静默遗漏。
