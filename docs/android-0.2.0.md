### 删除与撤销的实现选择

删除确认后订阅先从列表隐藏，5 秒后才真正写入本地数据和同步队列；撤销只是取消计时，不产生任何记录，因此不会多出一条"恢复"同步操作，也不会和服务器产生冲突。写入失败时订阅重新显示，提示条提供重试。网页端删除仍需输入账户密码，未改动。

### 下拉同步

页面滚到顶部时内容区切换为 `touch-action: pan-x pan-down`（W3C Pointer Events 规范中的下拉刷新写法），下拉手势交给页面处理。未连接服务器时只提示"未连接服务器"，不发请求；已连接时只触发一次同步，结果显示在顶栏同步状态点上。减少动态效果开启时不跟手，只显示静态文字。

### 触感反馈

依赖 `@capacitor/haptics` 8.x。开关保存在本机（振动属于设备，不随账号同步），默认开启，与"减少动态效果"互不影响。浏览器预览中不加载插件。

## 已知缺口

- 删除确认框左上角有一个额外的"取消"按钮，来自共用的 `BaseModal`，与底部"取消"重复，未在本版处理。
- 真机（PFVM10）已验收：时间轴、下拉手势（`3-device-pull-during.png`）、滚轮触感（系统振动记录中有 `com.easysub.app` 50ms 轻触）。续费成功和删除的振动没有在真机触发，因为会写入真实账号。
- 该手机的系统触摸振动强度为 0（振动记录 `scale: 0.00`），因此振动按系统设置被静音；这是系统行为，不是 App 问题。
- 真机五主题、三语言矩阵和逐帧动效未验收（不修改真实账号的偏好设置）。
- 仍是调试签名；正式签名方案在 0.3.0 阶段只出文档。
