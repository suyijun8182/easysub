# EasySub Android App 设计草案（debug21）

状态：产品边界已确认；首个 Android Alpha 安装包已生成，真机安装与后续原生功能进展见 [android-alpha.md](android-alpha.md)。本稿仍记录完整目标，不代表全部已实现。

## 已确认的范围

- 单人使用，免注册登录，数据存储在手机本地，核心管理离线可用。
- 覆盖网页版个人功能：订阅与保号、分类、支付方式、捆绑包、预算、日历、报表、记录、主题、语言、币种与通知配置。
- 本地通知为默认提醒，原有外部通知渠道作为可选联网能力；汇率离线使用缓存，联网更新。
- 保留 EasySub 品牌与现有主题，重做安卓导航、详情、表单和动效；网页继续维护，仅调整互通所需部分。
- 兼容网页 JSON 备份双向迁移；整站文件导入时选择一个用户。原“不做自动同步”约定已被 debug22 的新要求取代，规格见 [debug22-sync-spec.md](debug22-sync-spec.md)。服务器协议和持久化浏览器客户端已实现，原生交付待完成，详见 [验证记录](debug22-sync-status.md)。
- 完整备份包括通知密钥、Token、密码和本地图标，使用用户密码加密；密码丢失无法恢复。
- 支持 ICS 文件导出；Home Assistant 服务接口继续由网页服务提供。
- 每周摘要改为本地通知，自动备份遵循 Android 后台限制，显示最近成功时间。
- 现有 GitHub 仓库发布源码与签名 APK，签名密钥单独保管。

## 导航与页面

底部固定五个入口：总览 / 订阅 / 日历 / 报表 / 设置。保留各入口的滚动与筛选状态；详情和编辑页使用返回导航。系统返回优先关闭键盘、弹层，再返回上一页。

### 总览

首屏按处理优先级排列：过期未处理 → 即将到期 → 本月支出与预算。到期事项展示服务名称、金额与币种、到期日期、剩余天数和必要备注。颜色配合文字表达状态，不单靠红绿区分。

预算显示已用、剩余和周期；年度折算明确标注“估算”，不得与实际付款混淆。首页可直接进入订阅详情和新增订阅。

### 订阅

顶部搜索，下方分类筛选与排序。列表呈现图标、名称、套餐或备注、金额、周期、到期状态。搜索覆盖名称与备注；保留网页已有筛选能力。

右下角新增按钮避开系统手势区域。点按进入详情；长按进入批量选择，提供续费、启停、分类、删除，删除显示数量并确认。拖拽只在手动排序模式出现。

详情以到期日期、金额、周期和“续费”为重点，展开供应商、支付方式、捆绑包、家庭成员、VPS 地址等信息。续费先预览下一到期日与付款记录，再提交；不能因重复点按产生两笔记录。

### 新增与编辑

整页分组：服务与分类 → 金额、币种、周期与日期 → 提醒 → 更多信息。支持预设供应商、自定义图标、周期/自定义周期/买断，以及现有试用、取消截止、卡到期等字段。

更多信息折叠，不删除已有字段。使用适合数字、日期和文本的输入控件；字段错误就地显示。离开未保存表单时提示保存或放弃。保存成功回到来源页并定位目标。

### 日历

上方月份，下方所选日期的议程。今天有明确入口；日期标记与状态文字相互补充。点击事项进入详情；空日期显示“当天没有到期事项”。支持导出 ICS，通过系统文件选择和分享交付。

### 报表

顶部周期切换，依次展示支出总览、趋势、分类与明细；每个区域只突出一个主要图表。图表提供文字金额与明细列表，不能依赖触摸图表才能获取数据。

区分实际付款、周期折算与预测；显示汇率更新时间，离线沿用缓存并标记。保留 CSV 导出。

### 设置

分组入口：外观与语言 / 币种与预算 / 提醒与免打扰 / 外部通知 / 分类、支付方式、捆绑包 / 数据与备份 / 隐私与应用锁 / 通知与操作记录 / 关于与更新。

外部渠道配置在手机端安全保存，密钥默认隐藏；测试发送显示具体成功或失败结果，日志不输出密钥。无网时清楚说明需要联网。

## 首次使用与状态

首屏两个主要选择：“开始使用”“导入备份”。通知权限在用户首次启用提醒时申请；拒绝后仍可正常管理数据，并提供设置入口。应用锁为可选，具体认证方式使用设备支持能力。

空列表引导新增或导入；无搜索结果提供清除条件。保存失败保留输入，导入失败保留原数据；无网不阻挡本地操作。

## 视觉与交互规范

沿用 Countdown 语义：绿=正常、琥珀=临期、红=过期，主题改变底色与操作色。默认跟随系统浅深色，保留 ocean、forest、purple 选择。

页面左右留白 16dp，分组间距 24dp，基础间距 8dp；卡片圆角延续 14dp。交互目标至少 48dp，正文以 16sp 为起点，辅助文字 14sp，支持系统字体放大和 TalkBack。优先系统中文字体，数字使用等宽数字样式，字体与图标不依赖在线下载。

主要动作每屏突出一个。保存、续费提供明确结果反馈；破坏性操作使用确认对话框。敏感信息在应用锁开启时限制任务预览暴露。

页面转场约 200–250ms，展开与状态变化约 150–200ms，不使用连续装饰动画。跟随系统减少动画设置，降低或取消位移动画。触觉反馈限于确认和批量选择等必要操作。

## 数据与备份流程

导入：选文件 → 校验/解密 → 显示来源、用户、数量与兼容性问题 → 追加或替换 → 替换前生成安全副本 → 事务写入 → 结果摘要 → 重新安排通知。

旧分类、支付方式与捆绑包 ID 必须重映射，保持订阅关联。追加导入先预览重复项，未经确认不覆盖已有记录。错误密码、损坏文件、空间不足不得造成部分恢复。

完整备份使用经过认证的加密格式，包含格式版本、数据、图标及通知凭据，不自行发明加密算法。用户选择导出位置；自动备份使用预先授权目录，无法访问时显示失败和修复入口。

旧网页明文 JSON 可导入；手机完整导出默认加密。网页需增加对新格式解密的支持，并补齐试用结束、取消截止、付款卡信息等旧备份遗漏字段，才能声称双向完整恢复。日志不得记录密码或解密后密钥。

## 通知与后台任务

按订阅提醒天数、试用、取消截止、卡到期安排通知，遵守免打扰和用户时区。编辑、续费、删除、恢复备份后重新安排，撤销旧通知，避免重复。

手机重启、时区变化、通知权限变化后恢复或校验计划。提醒时间与通知权限状态可见；外部渠道失败不影响本地通知。后台联网发送与自动备份不能承诺服务器级准点，记录最近执行结果；应用打开时补检遗漏任务。

## 实现约束与验证

当前 Vue 页面通过 FastAPI/MySQL 工作，不能仅封装网页获得离线能力。框架与本地数据库选型尚未决定；应先验证持久化、通知、加密备份与原有业务逻辑迁移，再确定技术方案。

已连接 OPPO A56 5G，Android 12，物理分辨率 720×1600；布局应按系统逻辑尺寸验证，不能用物理像素直接推定 dp。

验收覆盖：飞行模式下全部核心 CRUD、杀进程后数据持久化、续费计算与重复提交、分类关联迁移、旧备份导入、新备份网页互通、密钥和图标完整恢复、错误密码/损坏文件回滚、本地提醒与重启恢复、外部渠道逐项发送测试、主题与字体放大、键盘/系统返回/手势区域，以及签名 APK 安装与升级保留数据。
