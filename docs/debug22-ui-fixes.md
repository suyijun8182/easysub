# debug22 UI 审计修正

按用户确认，使用 ui-ux-pro-max 规则修正当前 Vue 浏览器客户端。没有修改原生 Android 工程，也未部署。

| 审计项 | 实施 |
| --- | --- |
| 主题与语言 | 启动读取本地资料库偏好；支持跟随系统；非法历史值回退。增加资料库重启恢复测试。 |
| 设置页重复提交 | 统一 busy 门控、禁用字段组、可读状态提示；忙碌时拦截应用内离开，失败恢复交互并聚焦反馈。 |
| 详情返回 | 存在应用内历史时返回；直接打开、外部来源或连续详情历史时返回订阅列表。同步后详情随资料版本更新。 |
| 配色 | 复查确认日历已有移动端 `--text-soft` 覆盖，上一轮把共享样式视为最终颜色的判断不完整。本次扩展五套主题对背景、卡片和次级表面的对比测试，不为已覆盖项重复修改全站样式。 |
| 同步表单 | 明确标签与字段关联、就地错误、aria-invalid、aria-describedby、可聚焦错误摘要与字段链接；成功后聚焦确认区域。支持密码管理器与粘贴。 |
| 动效与反馈 | 页面淡入 180ms、淡出 120ms；弹层 180ms 入场、遮罩 120ms；按压反馈 100ms。只过渡 opacity/transform/颜色，不动画布局尺寸。减少动态效果时关闭动效。 |
| 翻译 | 同步页面、状态、确认、冲突操作、字段错误及顶部入口补齐中英俄词条；验证变量占位一致。非中文遇到未知服务器错误显示本地化说明，具体服务器消息仍需按协议扩展错误码。 |

保持五项底部导航、48px 主要触控目标与底部安全区。同步页动作间距统一为 12px，摘要点击区域为 48px。为输入、按钮和链接增加滚动定位余量，避免焦点落到底栏下方。

验证命令：`npm run test:android-preview`、`npm run test:sync`、`npm run build:android-preview`、`npm run build`。前两项共 27 项通过；需要独立服务端 fixture 的 1 项 HTTP 测试本轮跳过，此轮未修改同步协议。两套构建通过。

未完成：375px/横屏/放大字体/屏幕阅读器/键盘弹出状态的真实截图和手动操作验收。上一轮 Computer Use 因无法可靠识别浏览器 URL 停止；本轮仅完成源代码、数值对比与自动化验证，不宣称视觉或真机通过。
